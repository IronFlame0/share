## Аккаунт

- GitHub-логин: `IronFlame0`
- Почта для коммитов (задана локально в этом репозитории): `40169445+IronFlame0@users.noreply.github.com`
- Работать только в этой папке, другие репозитории не трогать. Глобальный git config не менять.

## Как оформлять страницы

- Каждая задача — подпапка с понятным латинским slug (например `trip-georgia/`) и самодостаточным `index.html`.
- Страница должна быть красивой: адаптивная вёрстка (нормально смотрится с телефона), светлая и тёмная тема через `prefers-color-scheme`, аккуратная типографика. Стиль можно брать с корневого `index.html`.
- Внешние ресурсы — только Google Fonts и CDN с зафиксированной версией (cdnjs/jsdelivr). Картинки — в той же подпапке.
- После создания страницы добавь её в оглавление корневого `index.html`: новый `<li>` в начало списка `ul.pages` (название, дата, одна строка описания). Образец разметки — в комментарии над списком.

## Публикация

1. Перед каждым push проверяй `gh auth status`: активен должен быть `IronFlame0`. Если активен другой аккаунт — остановись и скажи мне, не пушь.
2. Коммит → `git push` → дождись сборки Pages (`gh api repos/IronFlame0/share/pages/builds/latest`, статус `built`) → проверь, что ссылка отдаёт 200 (`curl -I`) → дай мне ссылку вида `https://ironflame0.github.io/share/<slug>/`.

## Безопасность

Всё, что публикуется, видно всему интернету. Никаких рабочих данных, кода и документов с работы, паролей, токенов, номеров документов и чужих персональных данных. Если в задаче есть сомнительное — спроси перед публикацией.
